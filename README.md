# Recharge

A mod manager for **IGTAP** (*an Incremental Game That's Also a Platformer*, the Steam Demo). A Tauri desktop app that installs/updates/toggles mods and maps, backed by [RechargeLoader](loader/README.md) — a lightweight mod-loading framework that patches one call into the game's own compiled code, no BepInEx or injector involved.

## Layout

- `app/` — the desktop app itself (Tauri 2 + vanilla JS). Home screen, Mods/Maps/Settings tabs, the in-app Map Editor.
- `loader/` — RechargeLoader: `build-loader.ps1` (decompile → patch → build → deploy) and the `ModApi`/`Runtime` mod-loading contract every mod builds against. See its own [README](loader/README.md) for how mods actually load.
- `mods/` — the real mods shipped on top of the loader: `recharge-multiplayer` (real-time multiplayer, aka DOTnet) and `recharge-maps` (a real-asset map system, including the map editor's runtime side).
- `content/` — the local mod/map catalog the app's Browse tab reads from (`index.json`, regenerated by `build-index.js`), plus each entry's packaged `.igtap` and gallery images.
- `tools/` — dev-only scripts: `devtools.js` (drives a running `tauri dev` instance over the Chrome DevTools Protocol for testing), `game-input.ps1` (a Win32 input harness for automated in-game testing).

## Installing

Run the installer from a [release](../../releases), or build it yourself:

```
cd app
npm install
npm run tauri build
```

The result lands in `app/src-tauri/target/release/bundle/nsis/`.

## Recharge Hub

The desktop app can also install content straight from [codecade.co.za/recharge](https://codecade.co.za/recharge), a community mod/map library. Clicking **Beam to Client** on a library page calls a local-only endpoint the app runs on `127.0.0.1:39284` ([`app/src-tauri/src/commands/hub.rs`](app/src-tauri/src/commands/hub.rs)), which downloads and installs the package directly — no manual file handling. Multiple items can be queued and installed in one go from the library page itself.
