Drop custom IGTAP emoji art here (e.g. igtap_jump.webp).

Register it in ../emojis.ts -> CUSTOM_EMOJIS:
  { shortcode: 'igtap_jump', url: 'social/emojis/igtap_jump.webp' }

Then :igtap_jump: renders inline in chat and appears in the picker's Custom tab.
build-ui copies this folder to ui/social/emojis/ as-is.
